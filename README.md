📊 Cyber Threat Analytics Platform with Incident Visualization System
🚀 Project Overview
This project was completed as part of our internship with Infosys Springboard Virtual Internship 7.0.

The Cyber Threat Analytics Platform with Incident Visualization System is an interactive data-driven cybersecurity analytics project designed to transform raw cybersecurity incident data into meaningful, interactive, and decision-ready insights.

The project analyzes 10,228 cybersecurity incident records spanning 141 countries from 1971 to 2024. Using Python, Pandas, Power Query, Power BI, DAX, and data modeling techniques, the raw incident data was cleaned, standardized, processed, and transformed into an interactive threat intelligence system.

The project demonstrates how data analytics and visualization can be used to understand cyber threats, identify attack patterns, analyze attacker behavior, discover vulnerable assets, and examine global incident trends. Through interactive dashboards and analytical reporting, the system helps convert complex cybersecurity data into clear and actionable insights.

🗂️ Dataset
The dataset used in this project consists of publicly available cybersecurity incident records obtained from Kaggle.

Dataset File: Dataset.csv (uploaded in this repository)
Total Records: 10,228+ cybersecurity incidents
Geographical Coverage: 141 countries
Time Coverage: Spans multiple decades
Key Features: Attack Type, Actor Type, Attacker Country, Target Country, Asset Variety, Cloud Environment, Motive, Incident ID, Year, and Month.

The dataset was analyzed and preprocessed to identify cybersecurity trends, attack patterns, affected regions, and other meaningful insights.

📊 Project Workflow
1. Data Collection & Understanding
The cybersecurity incident dataset was collected and examined to understand its structure, categories, missing values, and relationships. The dataset contained 10,228 records and 21 columns, covering incidents across 141 countries.

2. Data Cleaning & Preprocessing
The raw dataset contained inconsistent labels, missing values, ambiguous categories, and unknown information. A systematic preprocessing pipeline was used to standardize categories, handle missing values, encode and scale selected fields, and prepare the dataset for analysis.

3. Data Modeling
The cleaned data was structured into an analysis-ready model. Incident, actor, asset, attack, motive, and geographic dimensions were aggregated and related to support efficient cross-filtering and interactive exploration.

4. Dashboard Development
Using Power BI, seven interactive dashboards were developed:

Executive Summary
Threat Analysis
Attacker & Actor Intelligence
Asset Vulnerability
Incident Severity
Threat Pattern Deep Dive
Attack Pattern Analysis
5. Insights & Interpretation
Insights from multiple dashboards were combined to understand attack trends, dominant threat types, attacker behavior, motivations, targeted countries, and vulnerable assets.

6. Reporting & Decision Support
The final dashboards and reports were designed to communicate cybersecurity insights clearly and support faster, data-driven security analysis and decision-making.

📌 Key Insights
The analysis of the cybersecurity incident dataset revealed several important patterns:

10,228 cybersecurity incidents were analyzed across 141 countries.
The dataset covers incident records from 1971 to 2024.
Hacking was the dominant attack category, accounting for approximately 3.4K incidents.
Financial gain was one of the most significant motives, associated with approximately 3,951 incidents.
External actors appeared repeatedly across cybersecurity incidents.
The United States was the most frequently targeted country, with approximately 5K incidents.
Authentication-related and other critical assets appeared as recurring risk areas.
A significant number of incidents contained unknown or unconfirmed attacker identities or origin countries, making attribution an important analytical challenge.
These findings demonstrate the value of structured data preparation and interactive visual analytics for understanding complex cybersecurity patterns.
